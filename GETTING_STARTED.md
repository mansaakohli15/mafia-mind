# Getting Started with DeceptionAI

A beginner-friendly guide to running this project on your own machine, pushing it to GitHub, and deploying it.

> **You don't need any of this to use Lovable.** Lovable already runs the app in a preview and deploys it for you. This guide is only if you also want the project on your laptop and GitHub.

---

## 1. What you need to install (one-time)

1. **VSCode** — the code editor — https://code.visualstudio.com/
2. **Node.js (v20+)** — JavaScript runtime — https://nodejs.org/ (LTS version)
3. **Bun** — fast package manager this project uses — https://bun.sh/
   - macOS / Linux: `curl -fsSL https://bun.sh/install | bash`
   - Windows (PowerShell): `powershell -c "irm bun.sh/install.ps1 | iex"`
4. **Git** — version control — https://git-scm.com/downloads
5. **A GitHub account** — https://github.com/

After installing Git, tell it who you are (one-time, in a terminal):

```bash
git config --global user.name  "Your Name"
git config --global user.email "you@example.com"
```

---

## 2. Connect this Lovable project to GitHub

1. In Lovable, click the **GitHub** button (top right) → **Connect to GitHub** → authorize.
2. Click **Create Repository**. Lovable pushes the code to a new repo on your GitHub.
3. Go to https://github.com/ and confirm the repo exists.

From now on, every change you make in Lovable auto-commits to that repo.

---

## 3. Run the project on your laptop

Open **VSCode** → `Terminal` → `New Terminal`, then:

```bash
# 1. Clone your repo (replace with your URL)
git clone https://github.com/YOUR-USERNAME/YOUR-REPO.git
cd YOUR-REPO

# 2. Install dependencies
bun install

# 3. Start the dev server
bun run dev
```

Open http://localhost:3000 (or whatever port the terminal prints).

> The `.env` file with your Lovable Cloud keys is auto-generated by Lovable and committed to the repo. You don't need to create it yourself.

---

## 4. The git commands you'll actually use

```bash
git status                      # what changed?
git pull                        # get latest from GitHub (do this first!)
git add .                       # stage all changes
git commit -m "your message"    # save a snapshot locally
git push                        # send your commits to GitHub
```

**Typical loop:**

```bash
git pull
# ... edit files in VSCode ...
git add .
git commit -m "added voting screen"
git push
```

If you push from your laptop, Lovable will pull those changes into the preview automatically.

## 6. Deploying

The fastest path: click **Publish** in the top-right of Lovable. Done — you get a live `*.lovable.app` URL.

To use a custom domain, click **Publish → Add custom domain** after the first publish.

## 8. Troubleshooting

| Problem | Fix |
|---|---|
| `bun: command not found` | Restart your terminal after installing Bun. |
| `git push` rejected | Run `git pull --rebase` first, then push again. |
| Preview is blank | Check the VSCode terminal for red errors; usually a syntax error in the last file you edited. |
| Lost local changes | `git stash` saves them; `git stash pop` brings them back. |
| Wrong GitHub account in VSCode | Sign out from VSCode → Accounts (bottom-left), sign back in. |
